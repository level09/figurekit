# Publishing Style Routing

Call `list_styles` first. Treat its descriptions as canonical: the connected
server's catalog wins over this table. Use this guide to resolve editorial fit
when several styles appear suitable.

| Need | First choice | Alternate |
| --- | --- | --- |
| Field guides, cutaways, environments, how a system or place works | `living-diagram` | `studio-object` for one abstract relationship |
| Technology, security, infrastructure, economics, serious analysis | `minimal-noir` | `living-diagram` when the system needs a cutaway |
| News features, work and society, specific human situations | `graphic-chronicle` | `paper-riot` for a more graphic argument |
| Abstract concepts made physical: flow, balance, tension, trade-offs | `studio-object` | `minimal-noir` for a starker treatment |
| Opinion, satire, institutional friction, crowded human systems | `ink-caricature` | `paper-riot` for a less character-led treatment |
| Culture, campaigns, energetic public debate, visual metaphors | `paper-riot` | `graphic-chronicle` for a calmer scene |
| Profiles, memory, identity, relationships, grief, literary essays | `soft-signal` | `storybook-ink` when a narrative scene helps more |
| Short stories, picture books, gently satirical everyday narrative | `storybook-ink` | `soft-signal` for adult reflective work |
| Children's stories, family, play, early learning, personal warmth | `naive-crayon` | `soft-clay` for a more finished look |
| Friendly explainers, children's publishing, food, lifestyle, covers | `soft-clay` | `storybook-ink` for sequential scenes |

## Integrity

- Treat generated work as illustration, not evidence of a real event.
- Use symbolic scenes or non-identifiable figures for reporting about real people.
- Do not fabricate a recognizable public figure unless the user explicitly requests
  a clearly labeled fictional or satirical depiction.
- Do not reproduce a living artist's signature style or a publication's house style.
  Translate the request into medium, palette, line, lighting, and composition.
- Keep one visual language across an article, story, or book sequence unless the
  user explicitly requests a change.
